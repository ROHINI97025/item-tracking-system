# Item Tracking System

A console-based Item Tracking System developed in Python using Object-Oriented Programming (OOP) and JSON file storage.

## Features

- Add new items
- View all items
- Search items by ID
- Update item details
- Delete items
- Validate item quantity and duplicate IDs
- Store item records in a JSON file

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling

## Project Structure

```text
item-tracking-system/

```

## How to Run

Make sure Python is installed on your computer.

Run the following command from the project folder:

```bash
python item_tracking_system.py
```
